### _📃 description:_

```
This simple program only supports the Linux system and it helps you to know
the password of a specific network that you have connected earlure.
```
<br>

**⚠️ If you dont want this program, you can write the following command:**

```bash
cd /etc/NetworkManager/system-connections/    # Go to the folder
ls                                            # Display folder contents
sudo cat -n Wifi_Name                         # View file content
```
**🔍 Search for:**
```bash
  psk=password # this is network password
```
